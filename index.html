全部保存在这台设备的浏览器里，不会上传到任何地方。

Navidrome 服务器

填你自己的 Navidrome 地址和登录账号。地址填到域名或 IP 就行， /rest 会自动补上。
手头还没有服务器？—— Navidrome 官方的公开演示服务器，几百首免费音乐，可以直接试。

YouTube 搜索 可选

填了 key 才会在搜索结果里带上 YouTube，库里没有的歌也能直接放。 去 RapidAPI 上搜这两个 API 订阅一下（都有免费档），用同一个 key： yt-api（搜索）和 youtube-mp36（取音频）。 免费档有速率上限，key 可以填多个，用逗号隔开，会随机轮着用。 详细步骤和排错见项目 README。

AI 搜索纠错 可选

语音或手输容易出同音字（“告白气球” 听成 “告白汽球”）。填了 key 之后， 搜索会先让模型把词顺一遍，原词和纠正词的结果都会列出来。 任何兼容 OpenAI /chat/completions 的服务都可以。不填就完全不启用。

自建搜索后端 可选 · 进阶

如果你自己跑了一个搜索/取流的小服务，把地址填这儿就能接进来， 接口约定见仓库里的 docs/backend-api.md。不填就没有这一栏。
